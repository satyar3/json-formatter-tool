# 🧹 JSON Formatter & Validator

A simple, fast, and lightweight web tool to **format**, **validate**, and **debug JSON** data right in your browser. Built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- ✅ Paste raw or minified JSON
- ✅ Formats with proper indentation
- ✅ Validates JSON and shows errors clearly
- ✅ Works completely offline (client-side)
- ✅ No external libraries required
- ✅ Copy formatted JSON with one click (optional feature)

## 📂 How to Use

1. Paste your JSON into the input area.
2. Click “Format & Validate”.
3. See formatted output or error message below.
4. Optionally, click “📋 Copy Output” to copy the result.
